# YGO CardPrint

游戏王卡片查询、在线卡图选择与 A4 九宫格 Word 打印清单。

## 当前运行方式：本机清单 + 直接下载

- 卡名、效果词、卡片密码、CID 搜索和批量解析仍通过服务端查询百鸽 API。
- 简中、日文、英文及 YGOPro 在线卡图保留，同域代理继续校验图片来源、格式、尺寸与比例。
- 清单的卡片、图版、数量和顺序立即保存在用户当前浏览器的 localStorage，不再上传数据库，不自动过期。
- 沿用 `cardprint:project:v1` 缓存键，可读取旧版本已经留在此浏览器的清单副本；仅存在云端而没有本机副本的清单不会自动迁移。
- 清除网站数据、换浏览器或换域名会失去对原本机清单的访问。浏览器禁止存储或空间不足时，会提示清单仅在当前页面有效，但仍允许导出。
- 点击“导出 Word 文档”后将本次清单发送到 `/api/exports/direct`，服务端在线获取卡图并生成文件，响应直接下载到用户设备，不保存 Word 文件或导出任务。
- Word 保持 A4 纵向，每页 3 × 3，卡片 59 × 86 mm。每种图版 1～3 张，总数最多 120 张。
- 导出需要网络，生成和下载期间请保持页面打开；低清晰度卡图会提示，图片不可用或请求失败可以重试。

## 云端功能已暂停

项目同步、找回链接、云端导出任务及文件存储暂停。旧云端接口返回 `503` / `CLOUD_DISABLED`，不会连接数据库或 Blob。Vercel 自动清理任务已停用；数据库、Blob 中的现有数据没有被删除，也没有通过本次修改导出到本机。

卡图改用服务端可丢弃的文件缓存：本地开发为 `storage/card-images`，Vercel 为 `/tmp/ygo-cardprint/card-images`。缓存缺失时重新获取在线图片；缓存写入失败不阻止当次预览和导出。原有卡图源站回退、完整解码和清晰度校验保留。

当前运行不需要 MySQL、`DATABASE_URL`、`BLOB_STORE_ID`、`BLOB_READ_WRITE_TOKEN` 或 `CRON_SECRET`。旧云端代码、Prisma 模型和迁移保留供后续维护，暂停开关位于 `lib/cloud-features.ts`。恢复完整云端模式还需要恢复前端同步流程及定时任务，不能只切换此开关。

## 本地运行

安装 Node.js LTS 后执行：

```powershell
npm install
npm run dev
```

打开 http://localhost:3000。Windows 也可使用 `启动前端.bat` 或 `启动前端.ps1`。当前模式无需运行数据库迁移或数据库清理脚本；`启动项目.bat` 是旧云端模式的启动脚本。

## 验证与部署

```powershell
npm run lint
npm run typecheck
npm run build
```

Vercel 部署无需配置数据库和 Blob；已有变量可暂留，但当前页面、在线卡图和直接下载不会使用它们。代码修改需要重新部署才会在正式网址生效。

上线后验证：搜索并添加卡片，修改数量与顺序，刷新后恢复清单；不连接数据库或 Blob 时仍能直接下载 Word。另需在目标用户网络下验证域名访问，取消云端存储不能解决 Vercel 域名的 DNS 或网络线路问题。

卡片资料与图片来自百鸽及 YGOProDeck；请遵守来源服务的使用要求。
